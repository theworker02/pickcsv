# pickcsv

Pick CSV/TSV csv tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/pickcsv/

## Install / run

```bash
git clone https://github.com/theworker02/pickcsv.git
cd pickcsv
node src/cli.js
node --test
```
